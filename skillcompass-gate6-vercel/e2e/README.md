# اختبارات QA المتصفحية (Playwright)

تُشغّل هذه الاختبارات Chromium حقيقياً على `index.html` عبر خادم محلي مربوط بـ`127.0.0.1`. تُحجب كل الطلبات الخارجية من المتصفح، ويُسمح فقط بتسجيل نطاقات الخطوط والصور المعروفة في قائمة سماح صريحة. لا تُستخدم مفاتيح أو خدمات خارجية.

اختبارات المتصفح **ضمن Workflow الخاص بـQA V6 على GitHub Actions**، ويمكن تشغيلها محلياً أيضاً. يستخدم CI Node.js `26.x` ويثبّت Chromium قبل تنفيذ اختبارات المتصفح.

## المتطلبات

- Node.js `26.x`، وهو إصدار التشغيل الذي يتحقق منه Workflow.
- npm.
- Playwright `1.63.0` المثبّت من ملف القفل الملتزم به في المستودع.

## التشغيل من نسخة نظيفة

من داخل `skillcompass-gate6-vercel/`:

```bash
npm ci
npx playwright install chromium
npm run test:e2e:qa
```

- `npm ci` يثبت الاعتماديات وفق `package-lock.json` الموجود في Git، ولا يعيد إنشاء ملف القفل.
- يتحقق Workflow من إمكانية إعادة توليد ملف القفل دون أي فرق؛ أي تغيير غير مقصود يجعل CI يفشل.
- `npx playwright install chromium` يحمّل Chromium مرة واحدة لكل جهاز، ويحتاج اتصالاً بخوادم تنزيل Playwright.
- تُنفَّذ اختبارات المتصفح في CI من دون Network Guard الذي يمنع اتصالات Node المحلية؛ لأن خادم الاختبار يحتاج اتصال loopback إلى `127.0.0.1`. بدلاً من ذلك، يمنع اعتراض Playwright جميع الطلبات الخارجية ويؤكد اختبار مستقل أن الوجهات المحجوبة ضمن قائمة السماح فقط.
- يحفظ Playwright المتصفح في مساره الافتراضي، أو في `PLAYWRIGHT_BROWSERS_PATH` إن حُدّد.

## ما تغطيه

- التسجيل المحلي دون حقل كلمة مرور أو تخزينها.
- إعادة التسجيل أو تحديث الملف دون تصفير العملات أو تقدم الدروس أو معلومات المحاكاة.
- حذف حقل `password` القديم من الملف الشخصي دون المساس ببيانات التقدم.
- الحفاظ على التقدم القديم الذي لا يحمل علامة `progressSkill` داخل `legacyUnassignedProgress`، دون منحه تلقائياً لمهارة قد تكون غير صحيحة.
- رحلة محاكاة التسويق: رصيد صفر ← الدروس ← كسب العملات ← العودة ← خصم مرة واحدة ← متابعة.
- استعادة قيم الإنفاق بعد Refresh ثم خصم المبلغ الصحيح.
- فصل تقدم المهارات والتحقق من عدم تسربه بين المسارات.
- التعامل مع بيانات التقدم التالفة دون إسقاط SkillCoins.
- سلامة مسارات الملفات والروابط الرمزية في خادم الاختبار.
- فحص أخطاء الصفحة وConsole وفشل تحميل الملفات المحلية، والتحقق من نطاقات الطلبات الخارجية المحجوبة.
- اختبار API فعلي على Preview: GET غير مسموح (405)، بيانات مهارة/درس غير صالحة (400)، سؤال مطابق للدرس يُنتج إجابة، وسؤال خارج النطاق يُرفض.

## قيد الترحيل القديم

البيانات السابقة التي لا تحتوي `progressSkill` لا تكشف بصورة موثوقة المهارة التي تنتمي إليها كل أرقام الدروس؛ قد تكون ناتجة عن أكثر من مسار. لذلك تُحفظ المصفوفتان في `legacyUnassignedProgress` ولا تُحتسبان تلقائياً ضمن أي مهارة. العملات وباقي حقول التقدم تبقى كما هي. لا يوفر هذا الإصدار واجهة لاستعادة الإسناد اليدوي بعد؛ البيانات القديمة محفوظة في التخزين ويمكن بناء مسار استرداد صريح لها لاحقاً.

## الاختبارات الوحدوية

تعمل بـ`node --test` دون متصفح، ويشغّلها CI مع Network Guard:

```bash
node --test lib/localProfile.test.js lib/marketingBudget.test.js lib/indexPage.test.js
```


## اختبار API على Preview

يشغّل Workflow `preview-api-smoke.cjs` على عنوان فرع Preview. يختبر طريقة HTTP، والتحقق من المدخلات، واستجابة المعلم لسؤال من درس التجارة الإلكترونية 4، ورفض سؤال خارج نطاق الدرس. يعتمد الطلب على إعدادات OpenRouter الموجودة في Preview؛ لا يقرأ المفتاح ولا يمرره من GitHub Actions. إذا كانت حماية Vercel مفعلة، يستخدم الاختبار `VERCEL_AUTOMATION_BYPASS_SECRET` الاختياري من GitHub Actions Secrets دون طباعته.
